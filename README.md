# Personal Expense Tracker

A Python command-line interface application built to help users manage personal finances, log categorized expenses, and monitor budgets with SQLite persistent storage.

## Features
- **Persistent Storage:** Integrated SQLite database to store and retrieve transaction logs.
- **Budget Monitoring:** Real-time tracking of total expenditures against user budgets.
- **Category Summary:** Grouped breakdown for spending across categories (Food, Travel, Bills, etc.).
- **CRUD Operations:** Supports creating, reading, and deleting transaction records with timestamps.
- **Input Validation:** Error handling for invalid menu inputs and non-numeric amounts.

## Tech Stack
- **Language:** Python 3
- **Database:** SQLite3
- **Concepts:** Object-Oriented Programming (OOP), Data Encapsulation, SQL Integration
